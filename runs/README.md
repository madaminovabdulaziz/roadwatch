# Runs

Outputs of the organizers' harness (`run_submission.py`) kept as evidence, not deliverables.

- `kaggle_t4_official.json`: the official configuration (pacing on, `--time-factor 3`) on a Kaggle T4 with
  4 CPU cores, on the same code as `predictions_samples.json`. Its `log` is the runtime the website's home
  page and report show. The deliverable itself comes from an unpaced run (SPEC §12.54), whose own log
  was measured with a relaxed time factor.
