# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Hackathon judges (WIUT Hackathon 2026, elimination round) who score the site on its live demo, sample-video visualizations, EDA, approach and report, team, and design/UX. Secondary: anyone evaluating whether RoadWatch works on real road footage.

## Product Purpose
RoadWatch watches one fixed CCTV road camera and turns its footage into timed traffic events (14 classes: red light, wrong way, jaywalking, failure to yield, and others) plus a causal accident-risk score. The website shows the system working on real footage, explains how it works, and lets a visitor run it on their own clip.

## Positioning
Open weights, offline inference, one GPU: a pretrained detector and tracker, then calibrated scene geometry and explainable rules. Every event can be traced back to measured motion in metres.

## Capabilities and Constraints
- Static Next.js export (`web/`), data fetched at runtime from `public/data/` and generated by scripts; no hand-made numbers.
- Live demo backend is a CPU Hugging Face Space; the first 20 s of an upload are analysed.
- The site must never crash the demo flow and must stay online through judging.

## Brand Commitments
- Name: RoadWatch.
- The user pinned the visual reference for the site: the CADIS Aero landing (`~/dev/CADIS-landing`): full-bleed darkened video, one large headline bottom-left, tracked uppercase nav, Inter + IBM Plex Mono. Also cited: Palantir, Astro Mechanica.
- Home headline: "Intelligence for every road."
- Wanted: premium, one consistent color, fewer borders, nothing that reads as a template.

## Evidence on Hand
- Raw 4K samples `samples/C3902.MP4`, `samples/C3905.MP4` (fixed camera, Tashkent intersection).
- Annotated renders, event clips, risk curves: `web/public/data/results/`.
- Dev-set metrics `web/public/data/metrics.json`; runtime from the official 3× run.
- Team photos and affiliation logos: `web/public/data/team/`.
- No customers, testimonials, or deployments exist; never invent them.

## Product Principles
1. Show the system working on real footage before explaining it.
2. Every number on the site comes from a generated data file.
3. Honest about failure cases.
4. The demo path is always one click away.
